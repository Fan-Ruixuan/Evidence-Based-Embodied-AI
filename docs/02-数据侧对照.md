# 02 · 数据侧对照：证据化处理能否提升下游规划成功率？

> 状态：**占位符**。本篇对应 Roadmap 第二篇，实验尚未开展；启动后本文将被完整实验报告替换。
>
> 待检验假设（见[总纲](01-总纲-行之有据.md)）：同源视频经证据化处理与否，下游规划成功率差多少？

## 实验设计草图（非承诺，待迭代）

### 假设

对同一批原始操作视频，经过"证据化处理"（关键帧抽取 + 画面/语音/时间戳绑定 + 试错链标注）的数据，训练或评估下游规划任务时，任务成功率与样本效率显著优于未处理版本。

### 变量控制

- 同一批原始视频，两种组织方式（原始混沌流 vs 证据化结构化）；
- 同一个下游模型与同一套超参，仅数据组织不同；
- 评估协议固定，随机种子多次重复。

### 观测指标

- 主指标：任务成功率；
- 副指标：达到同等成功率的样本数（样本效率）；
- 过程指标：失败案例可归因比例（能否定位"失败在哪一瞬、哪步是关键决策"）。

### 交付物

- 同源视频的 A/B 实验报告（本文件替换稿）；
- 数据组织脚本与评估脚本（进入 `src/`）；
- 失败案例集（供第三篇校验层消融复用）。

## 已知风险

- 语义级 / 任务级数据对下游的收益可能小于关节级数据，效应量可能不显著——阴性结果同样会如实发布；
- 视频来源单一（自然操作）时结论外推有限，需在报告中明确适用范围。
