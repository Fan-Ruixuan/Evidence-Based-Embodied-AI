# 术语表

按主题分组，给出一句话定义与出处链接。术语在[总纲](01-总纲-行之有据.md)中的语境以本文为准。

## 底座：检索增强生成（RAG）

| 术语 | 定义 |
|---|---|
| RAG（检索增强生成） | 生成前先从知识库检索相关片段，让回答有据可依的技术路线 |
| 多模态 RAG | 检索对象包含文本与图像（本框架：文档 + 图片双链路解析） |
| 双链路并行解析 | 文本分层清洗、图像降噪/OCR/语义结构化后统一向量化，不丢视觉信息 |
| 父子双层分块 | 子块负责命中细节，父块负责补全上下文；重叠分片防止知识点被切碎 |
| 混合检索融合 | 关键词检索（命中术语参数）+ 向量检索（兜住语义相近表达）融合排序 |
| 证据溯源 | 每条生成结论强制绑定其依据的原始片段，可翻回验证 |
| 举证责任 | 任何结论都必须能出示其依据；检索正确不等于使用正确（见 Air Canada 案[^5]） |

## 具身智能与模型

| 术语 | 定义 |
|---|---|
| 具身智能（Embodied AI） | 以物理世界为作用对象、通过身体与环境交互的智能系统 |
| VLM（视觉语言模型） | 接收图像与文本、输出文本的多模态模型 |
| VLA（视觉语言动作模型） | 在 VLM 基础上直接输出机器人动作的端到端模型 |
| LLM（大语言模型） | 大规模文本生成模型，本框架语境中负责把描述转成动作序列 |
| 阶段幻觉（stage hallucination） | 模型汇报"进展顺利"而任务实际未完成的现象（EvoVLA，2025[^4]） |
| affordance（可供性） | 动作在当前环境下"可被执行"的程度，SayCan 用其与语言概率相乘选动作[^16] |
| sim-to-real 鸿沟 | 仿真数据与真实物理环境间的差异，摩擦、光照、材质稍变即可能失效 |
| 遥操作（teleoperation） | 人远程控制真机采集示教数据，质量高但成本高 |
| 场景图（scene graph） | 以图结构表示场景中实体及其空间/语义关系 |
| 行为树（behavior tree） | 以树结构组织机器人任务逻辑的执行框架 |
| CBF（控制屏障函数，Control Barrier Function） | 在控制层硬性保证状态不进入危险集合的数学方法[^19] |
| SafeVLA | 通过约束学习对 VLA 做安全对齐的工作（NeurIPS 2025[^19]） |
| 运动重定向（retromapping / retargeting） | 把人手运动映射为灵巧手构型，通行的表述是优化问题而非一一映射（DexMV[^12]） |
| 手眼标定 | 确定相机与机械臂坐标系关系的标定工序 |

## 本框架自有概念

| 术语 | 定义 |
|---|---|
| 过程留证 | 在数据入口把人的操作沉淀为任务级示教数据（时间朝后） |
| 动作举证 | 在动作出口要求候选动作出示空间证据后才放行（时间朝前） |
| 证据单元（Evidence Unit） | 贯穿采集与校验的最小证据载体：画面 + 语音 + 时间戳 + 决策 + 置信度 + 成败标注 |
| 试错链 | 按"问题 → 假设 → 调整 → 结果"组织的实验条目 |
| 空间元组 | 结构化空间关系：实体、关系类型、参考坐标系、可信度、观测性质 |
| 观测性质 | 证据是"亲眼所见"还是"推测"，缺省视为不可靠 |
| 参考坐标系 | 空间关系（左/右/前/后）的锚定基准；缺省即参考系混淆 |
| 双轨校验 | 确定性规则硬拦截 + 语义模型柔性复核，规则优先于模型 |
| 定向修正 | 拒绝动作时必须回传原因与可执行的改写建议 |
| 熔断 | 连续失败或证据不足即停止尝试、交还人工——承认"看不清、不能动" |

| EgoMimic | AR 眼镜第一人称视频 + 配对 3D 手部追踪 + 定制双臂机械手（2025[^9]） |
| EgoDex / HumanScale | 数百小时级人类视频数据集，过滤标注后预训练效果可超真机数据[^10][^11] |
